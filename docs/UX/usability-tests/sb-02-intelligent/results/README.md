# Usability Results Repository

This directory contains the raw session notes, raw data, and synthesized reports for the **Intelligent ERM (SB-02)** validation phase.

## Contents
- `/sessions/`: Raw 'Think Aloud' notes per participant.
- `/raw-data/`: Exported CSVs of timing and success metrics.
- `/final-reports/`: Consolidate findings based on the `shared/findings-report-template.md`.

> [!NOTE]
> All recordings are stored in the secure Media Server, not in this repository.
