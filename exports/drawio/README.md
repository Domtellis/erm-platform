# Draw.io exports

This folder contains draw.io files generated from `models/*/conceptual.mmd`.

How to import
1. Open https://app.diagrams.net/ or the desktop draw.io app
2. File → Import From → Device
3. Choose the `.drawio` file in this folder

Notes
- Files are generated automatically by `scripts/convert_mermaid_to_drawio.py`.
- Generated diagrams are simple layouts (boxes for classes/nodes and orthogonal edges). They are intended as a starting point for manual refinement in draw.io.
